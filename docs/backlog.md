# Бэклог доработок

Идеи и отложенные задачи, которые ещё не взяты в работу. Каждый пункт, когда до него дойдёт очередь, оформляется отдельным изменением OpenSpec (`/opsx:propose`). Детали в пунктах — черновые и уточняются при планировании.

## Профиль

### Поле «О себе»
- Необязательное текстовое поле в профиле пользователя: просмотр, заполнение при онбординге и редактирование.
- Затрагивает спеки `user-profile` (backend: новое поле, миграция, валидация) и `web-app` (форма и карточка профиля).
- Уточнить при планировании: максимальная длина, переносы строк, отображение длинного текста на мобильном.

### Минимальный возраст пользователя — 14 лет
- Дата рождения не может быть позже, чем «сегодня минус 14 лет». Пользователь, которому 14 исполняется сегодня, проходит.
- Проверка на backend (изменение требования «Валидация полей профиля» в `user-profile`) и на клиенте (ограничение выбора даты и ошибка у поля в `web-app`).
- Уточнить при планировании: текст ошибки; что делать с уже сохранёнными профилями младше 14 лет.

## Мероприятия

Вынесено за рамки `add-events` (backend мероприятий):

- Frontend мероприятий: каталог с фильтрами, карточка, форма создания и редактирования, запись и отказ, список участников.
- Просмотр полных профилей других участников мероприятия (сейчас в списке только `id` и имя).
- Управление категориями через API (добавление, переименование, удаление). Сейчас категории меняются только миграциями.
- Отмена мероприятия со статусом вместо жёсткого удаления; уведомления участников об изменении, удалении и исключении.
- Запрет повторной записи для участника, которого удалил организатор.
- Поиск по тексту, фильтр «мои мероприятия» (созданные и те, куда записан), прошедшие мероприятия в каталоге, другие сортировки.

## Отложено в предыдущих изменениях

Пункты, явно вынесенные за рамки уже реализованных изменений (см. разделы «Вне scope» в архивных proposal):

- Загрузка фото профиля (сейчас только отображение по `photo_url`).
- Смена телефона самим пользователем с подтверждением кодом на новый номер.
- Реальная отправка SMS. После неё убрать тестовую ручку кода и подсказку `DevCodeHint`.
- Тёмная тема и переключатель (конфигурация `.app-dark` уже подготовлена).
- Админские функции во frontend: просмотр и изменение чужих профилей.
- Видимость профиля для участников общих активных событий (вместе с активностями).
- Продакшен-сборка frontend и раздача статики.
- E2E-тесты в браузере.
