# Как подключить форму к Google Таблице (≈10 минут)

1. Создайте новую Google Таблицу, например «Заявки с сайта».
2. В таблице: **Расширения → Apps Script**.
3. Удалите всё в файле `Code.gs` и вставьте содержимое файла `apps-script/google-apps-script.gs`. Нажмите 💾 «Сохранить».
4. Справа вверху: **Начать развертывание → Новое развертывание**.
   - Тип (шестерёнка): **Веб-приложение**.
   - Запуск от имени: **Я**.
   - У кого есть доступ: **Все** (иначе сайт не сможет отправлять заявки).
   - Нажмите «Начать развертывание» и разрешите доступ своему аккаунту
     (Google предупредит, что приложение не проверено: «Дополнительные настройки → Перейти к проекту»).
5. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).
6. Откройте `web/index.html`, найдите строку `const SCRIPT_URL = "";` и вставьте адрес в кавычки:
   ```js
   const SCRIPT_URL = "https://script.google.com/macros/s/.../exec";
   ```
7. Отправьте тестовую заявку с сайта — через несколько секунд в таблице появится лист «Заявки» с новой строкой.

## Если поменяли скрипт
После изменений в Apps Script: **Развертывание → Управление развертываниями → ✏️ → Версия: Новая версия → Развернуть**. URL останется прежним.

## Уведомления о новых заявках
В таблице: **Инструменты → Правила уведомлений → «Пользователь вносит изменения» → «Сразу»** — Google будет присылать письмо на почту.
