# STANDARD.md — стандарт одностраничного сайта (финальная версия)

> С чего начинали — `STANDARD-v1.md`. Что изменилось — в конце файла, раздел 9.

Этот файл отдаётся ИИ вместе с задачей. Страница собирается **только** из компонентов ниже.
Стиль: светлый, спокойный, «воздушный» (референс — сайт студии йоги): оливковый + бежевый + розовый акцент.

## 1. Экраны
- Проверяемые ширины: **390, 768, 1440 px**.
- Правило: **нет горизонтальной прокрутки** ни на одной ширине (`document.documentElement.scrollWidth <= innerWidth`).
- Mobile first: базовые стили для телефона, расширение через `min-width: 768px` и `min-width: 1100px`.
- Кнопки и поля — высота не меньше **44 px** (удобно нажимать пальцем).

## 2. Сетка и отступы
- Шаг отступов: **8 px** (8, 16, 24, 32, 48, 64, 96).
- Поля контейнера: 16 px (телефон) → 24 px (планшет) → 32 px (десктоп).
- Максимальная ширина контента: **1200 px**, по центру.
- Отступ между секциями: 64 px (телефон) → 96 px (десктоп).
- Скругления: 12 px (поля, мелкие элементы), 24 px (карточки), 32 px (крупные блоки), 999 px (кнопки, плашки).
- Тени не используются, только тонкая рамка `1px solid --line`.

## 3. Типографика
- Заголовки: **Manrope** 700. Текст: **Inter** 400/500. Подключение Google Fonts с `display=swap`.
- H1: `clamp(34px, 6vw, 60px)`, межстрочный 1.1.
- H2: `clamp(28px, 4vw, 42px)`, межстрочный 1.15.
- H3: 20 px, межстрочный 1.3.
- Текст: 16 px (17 px на десктопе), межстрочный 1.6. Мелкий текст: 14 px. Меньше 13 px нельзя.

## 5. Компоненты
1. **Шапка** — круглый значок-логотип 52 px без подписи (рамка 1.5 px `#B89488`), меню-якоря (скрыто < 900 px), кнопка «Записаться». Липкая, белая.
2. **Первый экран** — плашка, H1 с розовым акцентным словом, абзац, 2 кнопки (основная + контурная), 3 цифры-факта, фото 4:5 справа (снизу на телефоне) с белой плашкой «Первое занятие — в подарок».3. **Кнопка** — `primary` (оливковая заливка, белый текст) и `secondary` (контур). Одна primary на экран.
4. **Плашка (pill)** — короткий ярлык: розовая или оливковая.
5. **Карточка** — белая, рамка, радиус 24 px, иконка 48 px + H3 + текст. Сетка 1 → 2 → 4 колонки.
6. **Шаги** — нумерованные карточки «как начать».
7. **Карточка цены** — название, цена крупно, пояснение, список, кнопка. Выделенная — оливковая рамка 2 px + плашка.
8. **Вопрос-ответ** — `<details>/<summary>`, без JS.
9. **Форма заявки** — подписи над полями (`<label>`), обязательные поля, согласие на обработку данных, ловушка для ботов, сообщение об успехе/ошибке. Отправка в Google Таблицу через Apps Script.
10. **Подвал** — тот же значок-логотип (64 px), полное имя, кратко об услуге, год.
11. **Доска с Роботом** — белая карточка: клетчатое поле (SVG) со стенами, Робот-ромб, программа на КуМире. Робот выполняет программу шаг за шагом (450 мс), текущая строка подсвечивается розовым, закрашенные клетки — оливковые. Анимация идёт только пока карточка на экране; при `prefers-reduced-motion` сразу показан итог.
12. **Блок «Обо мне»** — оливковая подложка, внутри две белые карточки одной высоты: текст (плашки, H2, абзацы, список) и «Доска с Роботом» (компонент 11). Обе заканчиваются розовой плашкой, прижатой к низу.

## 6. Технические правила
- Один `index.html` (CSS и JS внутри) + папка `images/`. Без сборщиков и фреймворков.
- У всех `<img>` есть `width`, `height`, `alt`; фото ниже первого экрана — `loading="lazy"`.
- Иконки — встроенный SVG, без библиотек иконок.
- Ключи и секреты в код не кладём (URL Apps Script — публичный, это допустимо).
- Семантика: `header`, `main`, `section` с `aria-labelledby`, `footer`; один `h1`.

## 7. Критерии проверки каждого шага
| Шаг | Как проверяю | Готово, если |
|---|---|---|
| Вёрстка блока | DevTools, режим устройства 390 / 768 / 1440 | нет горизонтальной прокрутки, ничего не наезжает |
| Цвета и шрифты | сравниваю с таблицей выше | нет цветов вне палитры, только 2 шрифта |
| Кнопки | клик по каждой | все якоря ведут к нужному блоку |
| Форма | отправляю тестовую заявку | строка появилась в Google Таблице меньше чем за минуту |
| Пустая форма | жму «Отправить» без данных | браузер подсвечивает обязательные поля, заявка не уходит |
| Lighthouse mobile | Chrome DevTools → Lighthouse | Performance ≥ 90, Accessibility ≥ 90 |
| Живой телефон | открываю ссылку на своём телефоне | всё читается, форма отправляется |

## 8. Правила, добавленные по ходу работы
Каждое правило появилось после конкретной ошибки или правки заказчика.

| # | Что случилось | Правило |
|---|---|---|
| 1 | ИИ сразу встроил эффект «фото открывается кусочками при наведении» — заказчику не понравилось, эффект удалили | **Анимации и эффекты** — сначала показать макет или демо, встраивать только после «да» |
| 2 | В карточке «Обо мне» был пример кода на Python — заказчику он показался чужим | **Примеры в оформлении** — из предметной области заказчика (для ОГЭ — Робот на КуМире), а не «код вообще» |
| 3 | Карточки в блоке «Обо мне» были разной высоты, под одной зияла пустота | **Карточки в одном ряду** — одной высоты: растягиваются по высоте, последний элемент прижат к низу (`margin-top: auto`) |
| 4 | Цифра «почти все на "5"» заменена на «90%»; в просьбе было «оценку 50» — уточнили, что это «5» | **Цифры и факты** — только со слов заказчика; если число странное, переспросить, а не угадывать |
| 5 | Логотип с мелким текстом в шапке не читался, а подпись рядом заказчику не понравилась | **Логотип в шапке** — только значок 52 px без подписи; мелкий текст логотипа не уменьшать |
| 6 | Фото заказчика весили 1,8–2 МБ | **Фото** — обрезать до 800×1000 (4:5), JPEG ≤ 100 КБ; исходники лежат рядом, но страница их не подключает |
| 7 | Во встроенном браузере не было видно фото, хотя в Edge было | **Предпросмотр** — открывать через локальный сервер (`localhost`), а не как файл |
| 8 | Форма показывает «Спасибо», даже если строка не записалась (ответ Apps Script прочитать нельзя) | **Проверка формы** — считается пройденной, только когда строка видна в таблице |
| 9 | Скриншот анимации Робота «соврал»: Робот был не в той клетке | **Проверка анимации** — по логу состояния (шаг, клетка, строка), а не по одному скриншоту |
| 10 | Headless Edge не умеет окно уже ~500 px, скриншот 390 px получался обрезанным | **Скриншот телефона** — страница во `<iframe>` шириной 390 px |
| 11 | Номера заданий ОГЭ легко перепутать | **Содержание про экзамен** — темы без номеров заданий, если номер не подтверждён |
