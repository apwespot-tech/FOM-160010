# Spec Delta

## MODIFIED Requirements

### Requirement: Фильтры и состояние списка
Над списком SHALL быть панель фильтров: поиск по названию, город (вариант «Все города», см. «Фильтр по городу в списке»), категория (вариант «Все категории»), даты в одном поле (первый клик выбирает один день, второй — конец диапазона; даты в часовом поясе браузера, конечная включается) и «Свободных мест от» (1–100); под ними — быстрые фильтры и «Сбросить», видимая, когда активен поиск или любой фильтр, и очищающая их все. Вкладка, период, поиск и фильтры MUST храниться в адресе страницы, чтобы ссылка и «Назад» восстанавливали список. На мобильной ширине поиск и быстрые фильтры видны всегда, а город, категория, даты и места открываются кнопкой «Фильтры» с числом активных из них.

#### Scenario: Фильтр по диапазону дат
- **WHEN** пользователь выбирает диапазон с 1 по 2 декабря
- **THEN** клиент запрашивает `from` = начало 1 декабря и `to` = начало 3 декабря по времени браузера

#### Scenario: Один день одним кликом
- **WHEN** пользователь один раз нажимает на 1 декабря в календаре фильтра
- **THEN** список сразу загружается с `from` = начало 1 декабря и `to` = начало 2 декабря; следующий клик по более поздней дате расширяет диапазон

#### Scenario: Свободные места
- **WHEN** пользователь вводит «Свободных мест от» 3
- **THEN** клиент запрашивает `min_free_places=3`, а в адресе появляется `places=3`

#### Scenario: Ссылка с фильтрами
- **WHEN** пользователь открывает `/?tab=joined&period=past&category=3&q=йога`
- **THEN** выбраны вкладка «Участвую», период «Прошедшие», категория «Спорт», в поиске «йога», список загружен с этими параметрами

#### Scenario: Сброс фильтров
- **WHEN** активны поиск, город, категория и даты, и пользователь нажимает «Сбросить»
- **THEN** поиск и все фильтры очищаются, их параметры удаляются из адреса, список загружается без них, «Сбросить» скрывается

#### Scenario: Панель на мобильном
- **WHEN** список открыт на ширине 360 px, выбраны город, категория и места
- **THEN** поле поиска и быстрые фильтры видны над списком, кнопка показывает «Фильтры (3)», горизонтальной прокрутки нет

## ADDED Requirements

### Requirement: Фильтр по городу в списке
Поле «Город» SHALL быть в панели фильтров на всех вкладках списка и по умолчанию показывать «Все города» — без фильтра. Варианты: «Все города», затем город из профиля пользователя с подписью «ваш город», затем остальные города справочника по алфавиту без повтора; без города в профиле — сразу все по алфавиту. В списке MUST быть поиск по названию. Выбор хранится в адресе как `city=<id>` и запрашивается как `city_id`.

#### Scenario: По умолчанию все города
- **WHEN** пользователь с городом «Казань» в профиле открывает `/`
- **THEN** поле показывает «Все города», запрос списка отправляется без `city_id`, в адресе нет `city`

#### Scenario: Город из профиля первым
- **WHEN** пользователь с городом «Казань» в профиле открывает список городов в фильтре
- **THEN** первым идёт «Все города», вторым — «Казань» с подписью «ваш город», дальше остальные города по алфавиту, и «Казань» среди них не повторяется

#### Scenario: Без города в профиле
- **WHEN** у пользователя в профиле не указан город
- **THEN** после «Все города» идут все города по алфавиту, подписи «ваш город» нет

#### Scenario: Выбор города
- **WHEN** пользователь выбирает «Казань»
- **THEN** клиент запрашивает список с `city_id` Казани, в адресе появляется `city=<id Казани>`, становится видна «Сбросить»

#### Scenario: Возврат ко всем городам
- **WHEN** выбрана «Казань», и пользователь выбирает «Все города»
- **THEN** параметр `city` удаляется из адреса, список загружается без `city_id`

#### Scenario: Поиск в списке городов
- **WHEN** пользователь открывает список городов и вводит «каз»
- **THEN** в списке остаются города, в названии которых есть «каз», без учёта регистра

#### Scenario: Город на других вкладках
- **WHEN** выбрана «Казань», и пользователь переходит на вкладку «Участвую»
- **THEN** поле «Город» по-прежнему показывает «Казань», список запрашивается со `scope=joined` и `city_id` Казани

#### Scenario: Ссылка с городом
- **WHEN** пользователь открывает `/?tab=organized&city=<id Казани>`
- **THEN** выбрана вкладка «Организую», в поле «Город» — «Казань», список загружен с `city_id` Казани

#### Scenario: Некорректный город в адресе
- **WHEN** пользователь открывает `/?city=abc`
- **THEN** поле показывает «Все города», список загружается без `city_id`
