## MODIFIED Requirements

### Requirement: Валидация полей профиля
Система SHALL отклонять с 422 некорректные значения: `name` — 1–100 символов после обрезки пробелов; `birth_date` — не позже текущей даты минус 14 лет (сообщение «Сервисом можно пользоваться с 14 лет») и не раньше `1900-01-01`; `email` — корректный адрес; `telegram` — `@` и 5–32 символа из латинских букв, цифр и `_`; `about` — до 500 символов после обрезки пробелов (пустая строка сохраняется как `null`); `city_id` — существующий город (`city_not_found`); `interest_ids` — список существующих категорий без повторов (`category_not_found`); `phone` — номер, приводимый к E.164.

#### Scenario: Дата рождения в будущем
- **WHEN** пользователь задаёт `birth_date` на день позже текущей даты
- **THEN** система отвечает 422 и профиль не меняется

#### Scenario: Дата рождения равна текущей
- **WHEN** пользователь задаёт `birth_date`, равную текущей дате
- **THEN** система отвечает 422 с сообщением «Сервисом можно пользоваться с 14 лет»

#### Scenario: Пользователю меньше 14 лет
- **WHEN** текущая дата `2026-11-05`, а пользователь задаёт `birth_date` = `2012-11-06`
- **THEN** система отвечает 422 с сообщением «Сервисом можно пользоваться с 14 лет», профиль не меняется

#### Scenario: 14 лет исполняется сегодня
- **WHEN** текущая дата `2026-11-05`, а пользователь задаёт `birth_date` = `2012-11-05`
- **THEN** значение принимается

#### Scenario: Ранее сохранённый профиль младше 14 лет
- **WHEN** у пользователя уже сохранена `birth_date`, по которой ему меньше 14 лет, и он меняет только `about`
- **THEN** изменение сохраняется, `birth_date` не меняется, `profile_completed` равен `true`

#### Scenario: Администратор задаёт возраст младше 14
- **WHEN** администратор отправляет `PATCH /profile/{id}` с `birth_date`, по которой пользователю 13 лет
- **THEN** система отвечает 422

#### Scenario: Пустое имя
- **WHEN** пользователь задаёт `name` из одних пробелов
- **THEN** система отвечает 422

#### Scenario: Некорректный Telegram
- **WHEN** пользователь задаёт `telegram` равным `@abc`
- **THEN** система отвечает 422

#### Scenario: «О себе» на границе
- **WHEN** пользователь задаёт `about` из 500 символов, а затем из 501
- **THEN** первое значение сохраняется с переносами строк, второе — 422

#### Scenario: Несуществующий город
- **WHEN** пользователь задаёт `city_id`, которого нет в справочнике
- **THEN** система отвечает 422 с кодом `city_not_found`

#### Scenario: Несуществующая или повторённая категория в интересах
- **WHEN** пользователь передаёт `interest_ids` с несуществующей категорией или с одной категорией дважды
- **THEN** система отвечает 422 и интересы не меняются

### Requirement: Получение изображений профиля
Система SHALL по `GET /users/{id}/images/{image_id}` отдавать аватар или обложку пользователя (`size=thumb` — уменьшенная копия WebP шириной до 800 px) любому авторизованному пользователю, в том числе с незаполненным профилем: аватар организатора видят и незаписанные. Картинка с данным `id` не меняется, поэтому ответ MUST разрешать личный кеш браузера бессрочно и MUST NOT разрешать общие кеши. Не текущая картинка этого пользователя — 404, недопустимый `size` — 422.

#### Scenario: Аватар организатора для незаписанного
- **WHEN** пользователь, не записанный на мероприятие, запрашивает аватар его организатора по `avatar_id` из ответа мероприятия
- **THEN** система отвечает 200 с картинкой и заголовком `Cache-Control: private, max-age=31536000, immutable`

#### Scenario: Аватар для черновика
- **WHEN** пользователь с незаполненным профилем запрашивает аватар организатора мероприятия
- **THEN** система отвечает 200 с картинкой

#### Scenario: Уменьшенная копия
- **WHEN** пользователь запрашивает обложку с `size=thumb`
- **THEN** система отвечает 200 с WebP шириной не больше 800 px

#### Scenario: Картинка другого пользователя по чужому адресу
- **WHEN** пользователь запрашивает `avatar_id` пользователя A по адресу пользователя B
- **THEN** система отвечает 404

#### Scenario: Без токена
- **WHEN** клиент запрашивает картинку без токена
- **THEN** система отвечает 401
