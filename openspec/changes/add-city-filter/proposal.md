# Proposal

## Why

Город у каждого мероприятия обязателен, но в списке мероприятий по нему нельзя отфильтровать: пользователь видит встречи во всех городах вперемешку. Пункт «Фильтр каталога по городу» уже был в бэклоге. Без фильтра в общем каталоге почти невозможно найти компанию рядом.

## What Changes

- `GET /events` принимает параметр `city_id`: возвращаются только мероприятия этого города. Фильтр работает при любых `scope` и `period` вместе с остальными, и `total` учитывает его. Несуществующий город — 422 `city_not_found`.
- В панели фильтров списка появляется поле «Город» на всех вкладках: «Найти компанию», «Участвую», «Организую».
  - По умолчанию выбрано «Все города» (фильтр не задан).
  - В выпадающем списке после «Все города» первой строкой стоит город из профиля пользователя с подписью «ваш город», затем остальные города по алфавиту без повтора. Если в профиле город не указан, список идёт просто по алфавиту.
  - В списке есть поиск по названию города.
- Выбранный город хранится в адресе страницы (`city=<id>`) вместе с остальными фильтрами, учитывается в «Сбросить» и в счётчике «Фильтры (N)» на мобильной ширине, где поле открывается в окне «Фильтры».
- Пункт «Фильтр каталога по городу» удаляется из `docs/backlog.md`.

## Вне scope

- Автоматический выбор города из профиля при открытии списка: по умолчанию всегда «Все города».
- Выбор нескольких городов, фильтр по расстоянию или району.
- Город на карточке и в окне мероприятия — он уже показывается, изменений нет.
- Добавление городов пользователями (отдельный пункт бэклога).

### Modified Capabilities
- `events`: каталог мероприятий получает фильтр по городу (`city_id`).
- `web-app`: в панели фильтров списка появляется поле «Город» с городом из профиля первой строкой, его значение хранится в адресе.

## Impact

- Backend: `app/routers/events.py` (параметр `city_id`), `event_service.list_events` (условие и проверка города), тесты каталога.
- API: новый необязательный параметр `GET /events?city_id=` — обратно совместим.
- Frontend: `useEventListQuery` (состояние, адрес, параметры запроса, счётчик активных), `EventFilters.vue` (поле «Город» в панели и в окне «Фильтры»), `EventsView.vue`, тесты списка.
- Документация: `docs/backlog.md`.
