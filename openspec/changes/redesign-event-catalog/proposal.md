# Proposal

## Why

Каталог мероприятий сейчас — текстовые карточки без картинок, а фильтры не умеют искать по названию: найти нужное мероприятие и оценить его с одного взгляда трудно. По новому макету карточки получают обложку, понятный статус набора и полосу заполненности, а над списком — поиск и быстрые фильтры. Фото мероприятий уже есть (`add-event-photos`), но для карточек нужны лёгкие уменьшенные копии и картинка по умолчанию, когда организатор фото не загрузил.

## What Changes

- **Backend** (`events`):
  - у категории появляются `icon` (имя иконки primeicons) и обязательная картинка-обложка; категорию без картинки сохранить нельзя (ограничение БД); для четырёх существующих категорий картинки генерируются (однотонный фон и значок категории, без текста и градиентов) и загружаются миграцией;
  - в ответах категории (`GET /categories` и поле `category` мероприятия) появляются `icon` и `cover_id`;
  - `GET /categories/{id}/covers/{cover_id}` отдаёт картинку категории (новая картинка — новый адрес), `?size=thumb` — уменьшенную копию;
  - `GET /events/{id}/photos/{photo_id}?size=thumb` отдаёт уменьшенную копию фото мероприятия; копии создаются при загрузке, для уже сохранённых фото — миграцией;
  - `GET /events` принимает `q` — поиск по подстроке в названии без учёта регистра, вместе с остальными фильтрами.
- **Frontend** (`web-app`):
  - правый блок шапки по макету: кнопка «Создать мероприятие», колокольчик без счётчика, аватар — скруглённый квадрат с инициалами;
  - заголовок «Мероприятия» с подзаголовком; вкладки без изменений;
  - панель фильтров карточкой: поиск по названию, категория, даты, «Свободных мест от»; быстрые фильтры «Есть свободные места» и «На этой неделе»; «Сбросить»; поиск хранится в адресе (`?q=`);
  - новая карточка: обложка (уменьшенная копия основного фото, а без фото — картинка категории), на обложке тег категории с иконкой, дата на плашке и отметка «Вы записаны» / «Вы организатор» / «Мест нет»; ниже название, возраст, место, «Осталось N из M мест», статус и полоса заполненности;
  - сетка карточек: 1 колонка на мобильном, 2 на планшете, 3 на компьютере.
- **Документация**: `docs/architecture.md` (картинки категорий, уменьшенные копии), `README.md` (поиск, быстрые фильтры), `docs/backlog.md` (убрать сделанное).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `events`: «Справочник категорий» (иконка и обязательная картинка), «Получение фото мероприятия» (уменьшенная копия); новые требования: картинка категории, уменьшенные копии фото, поиск по названию в каталоге.
- `web-app`: «Шапка приложения» (правый блок), «Фильтры и состояние списка» (панель, поиск, «Сбросить»), «Карточка мероприятия в списке» (обложка, статус, полоса), «Пустые состояния списка» (поиск); новые требования: заголовок страницы, поиск по названию, быстрые фильтры, обложка карточки.

## Impact

- Backend: модель и миграция Alembic `0004` (поле `icon`, таблица `category_covers`, `categories.cover_id NOT NULL`, столбец уменьшенной копии у фото и заполнение для существующих), готовые картинки категорий в репозитории и скрипт их генерации, `schemas/event.py`, `services/event_service.py`, `services/photo_processing.py`, `services/photo_service.py`, `routers/categories.py`, `routers/events.py`, тесты.
- Frontend: `AppHeader.vue`, `ProfileMenu.vue`, `NotificationsButton.vue`, `EventsView.vue`, `EventFilters.vue`, `EventListCard.vue`, `useEventListQuery.ts`, `api/events.ts`, `usePhotoUrl.ts` (кеш по размеру и картинки категорий), новые компоненты, тесты Vitest.
- API обратно совместим: добавляются поля и необязательные параметры.

## Вне scope

- Счётчики во вкладках «Найти компанию / Участвую / Организую».
- Логотип, название и навигация в левой части шапки; отметка непрочитанных уведомлений на колокольчике.
- Картинка категории в окне мероприятия (там без фото галереи по-прежнему нет).
- Создание, изменение и удаление категорий через API — категории по-прежнему добавляются миграциями.
- Поиск по описанию и месту, сортировки.
- Настоящие фотографии для категорий (сейчас — сгенерированные картинки; заменяются отдельной миграцией).
